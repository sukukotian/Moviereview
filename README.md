# Movie Review & Rating Web Application

A basic movie review and rating web application built using Node.js, Express.js and EJS.

This project was created to practice REST APIs, CRUD operations, Express routing, EJS templating, HTML forms and method override.

## Features

- View all movie reviews
- View a single movie review in detail
- Create a new movie review
- Edit an existing movie review
- Delete a movie review
- Unique ID for every review using UUID
- EJS templates for dynamic pages
- CSS styling using Express static files
